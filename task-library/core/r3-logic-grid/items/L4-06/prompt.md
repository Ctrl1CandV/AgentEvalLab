## Puzzle L4-06

There are 7 houses in a row, numbered 1 to 7 from left to right. One person lives in each house. Each attribute below takes each of its values in exactly one house.

- Name: Arlo, Cato, Fenna, Galen, Hollis, Ilse, Joren

- Drink: cider, cocoa, coffee, milk, oolong, soda, water
- Job: baker, chemist, florist, librarian, nurse, pilot, potter
- Hobby: birding, climbing, knitting, origami, pottery, rowing, sailing
- Fruit: apricot, banana, cherry, fig, guava, lychee, quince
- Sport: badminton, golf, hockey, judo, polo, rugby, squash
