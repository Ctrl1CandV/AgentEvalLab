## Puzzle L4-01

There are 7 houses in a row, numbered 1 to 7 from left to right. One person lives in each house. Each attribute below takes each of its values in exactly one house.

- Color: amber, coral, ivory, jade, lilac, maroon, slate
- Pet: axolotl, ferret, gecko, parrot, rabbit, tortoise, whippet
- Drink: cocoa, kefir, lemonade, milk, oolong, soda, water
- Job: architect, baker, florist, librarian, nurse, pilot, potter
- Hobby: archery, birding, climbing, fencing, knitting, rowing, sailing
- Fruit: apricot, banana, cherry, fig, guava, kiwi, lychee
- Vehicle: bicycle, canoe, moped, scooter, sedan, tram, van
