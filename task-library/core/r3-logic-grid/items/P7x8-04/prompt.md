## Puzzle P7x8-04

There are 7 houses in a row, numbered 1 to 7 from left to right. One person lives in each house. Each attribute below takes each of its values in exactly one house.

- Color: amber, cobalt, coral, ivory, jade, slate, teal
- Pet: axolotl, canary, gecko, hamster, parrot, tortoise, whippet
- Drink: cider, cocoa, lemonade, matcha, oolong, soda, water
- Job: architect, chemist, courier, florist, librarian, nurse, pilot
- Fruit: apricot, cherry, fig, guava, kiwi, mango, quince
- Instrument: banjo, clarinet, drums, harp, oboe, trumpet, viola
- Sport: cricket, curling, handball, hockey, judo, polo, squash
- Vehicle: canoe, glider, moped, scooter, sedan, tandem, tram
