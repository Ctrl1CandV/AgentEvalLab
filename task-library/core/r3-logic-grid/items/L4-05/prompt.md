## Puzzle L4-05

There are 7 houses in a row, numbered 1 to 7 from left to right. One person lives in each house. Each attribute below takes each of its values in exactly one house.

- Name: Bryn, Cato, Dara, Fenna, Hollis, Ilse, Joren
- Color: coral, jade, lilac, maroon, ochre, slate, teal
- Pet: canary, gecko, hamster, parrot, rabbit, tortoise, whippet
- Job: baker, chemist, courier, florist, librarian, pilot, potter
- Fruit: banana, cherry, fig, guava, kiwi, papaya, quince
- Sport: badminton, cricket, golf, handball, judo, polo, squash
- Vehicle: bicycle, glider, kayak, scooter, sedan, tandem, van
