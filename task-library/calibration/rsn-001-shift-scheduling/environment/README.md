# rsn-001 Environment

The task runs under Python 3.13 with the standard library only. The candidate receives the instruction and public instances. The evaluator uses a private oracle and verifier; those materials must remain outside the candidate workspace.

Historical offline checks validate the enumerated conflict set, the missing-parameter response, and schedule feasibility. The task has not been run against a real model. It covers a small synthetic constraint problem and does not establish general scheduling or CSP capability.
