## Puzzle L5-08

There are 8 houses in a row, numbered 1 to 8 from left to right. One person lives in each house. Each attribute below takes each of its values in exactly one house.

- Name: Arlo, Bryn, Dara, Elio, Fenna, Hollis, Ilse, Joren

- Pet: axolotl, canary, ferret, gecko, parrot, terrier, tortoise, whippet
- Drink: cider, cocoa, coffee, kefir, matcha, milk, oolong, soda
- Job: architect, baker, chemist, courier, florist, nurse, potter, welder
- Instrument: banjo, cello, clarinet, drums, harp, oboe, trumpet, viola
- Sport: badminton, cricket, curling, golf, handball, hockey, judo, rugby
- Vehicle: bicycle, canoe, glider, moped, scooter, sedan, tram, van
