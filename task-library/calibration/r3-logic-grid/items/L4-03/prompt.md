## Puzzle L4-03

There are 7 houses in a row, numbered 1 to 7 from left to right. One person lives in each house. Each attribute below takes each of its values in exactly one house.

- Name: Arlo, Bryn, Cato, Fenna, Hollis, Ilse, Joren
- Color: amber, coral, ivory, lilac, maroon, slate, teal
- Pet: canary, ferret, hamster, parrot, rabbit, tortoise, whippet
- Hobby: archery, chess, climbing, fencing, knitting, origami, rowing
- Fruit: apricot, banana, cherry, kiwi, mango, papaya, quince
- Sport: cricket, curling, golf, handball, hockey, rugby, squash
- Vehicle: canoe, glider, kayak, moped, scooter, sedan, van
