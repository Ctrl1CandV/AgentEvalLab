# Task: Finance Desk (T2)

You keep the books of a small freight company during its September close. Everything is in the directory `public/` of the workspace: the finance manual, `MANUAL.md`; the books, in `data/`; and the ledger tool, `ledger.py`. Run commands from inside `public/`, for example `python3 ledger.py open-items C-101`.

Handle the queue of requests below exactly as the manual says. Change the books only through `ledger.py`, and end with the JSON reply that `MANUAL.md` describes.
