# Task Collection Report

## Current set

The working candidate set covers five engineering tasks, two reasoning tasks, one tool-evidence task, and one frontend task. Each task has its own family and contract. Some task cards are more mature than their calibration packages.

## Calibration evidence

Objective packages include trusted graders, versioned public projections, private fixtures, and offline reference or mutation records. These records establish only the cases they list. Human review and browser rendering remain separate gates where required.

## Use limits

- Do not count related variants as independent task samples.
- Do not treat a candidate card as a frozen benchmark.
- Do not infer model capability from reference implementation calibration.
- Record any task exposure and version changes before a model pilot.
