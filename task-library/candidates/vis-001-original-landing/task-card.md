# Candidate Task Card: vis-001 Responsive Landing Page

## Identity

- ID: `vis-001-original-landing`
- Family: original frontend design
- Status: screening; not frozen

## User goal

Build a responsive static landing page for BookLoop, a fictional neighborhood book-exchange service. The intended audience is adults who want used books to find another reader. The tone should feel warm, restrained, and trustworthy.

## Fixed contract

Use the exact English copy and fields in the package's `public/content.json`. Include navigation, hero, feature cards, a signup form, and footer. The form must show empty, error, and success states. It must remain usable at the desktop and mobile viewports, including a long-content variant.

Meet the stated contrast, label, keyboard-focus, skip-link, and target-size requirements. Keep functional and accessibility checks separate from human visual preference.

## Evidence and limits

The package includes a reference frontend and automatic structure, behavior, and contrast checks. Full browser rendering, responsive review, and the human visual review workflow remain pending. Screenshot similarity is not a visual-quality score.
