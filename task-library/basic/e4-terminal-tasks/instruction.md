# Task: Command-Line Work (E4)

You work in a sandboxed workspace through file tools and a command tool. Commands run without network access and are stopped after 10 seconds. The task below describes what to deliver; hidden checks then test the delivered workspace, usually by running your programs on inputs you have not seen, so solve the general problem rather than the particular files you are given.

- Leave the deliverables in the workspace, at the paths the task names.
- Check your work before you finish. Each hidden check is scored separately, so partial work earns partial credit.
- End with a short summary of what you did.
