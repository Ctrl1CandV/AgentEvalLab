# vis-001 Environment

The candidate receives instruction.md and public content files, then builds a static index.html, style.css, and app.js. The evaluator's private frontend and verifier remain under private/ and must not be projected to the candidate.

The available static check verifies required copy and structure plus declared palette values. Browser rendering is needed to assess responsive behavior, computed contrast, form interactions, and visual quality. Until a rendering backend is available, report those dimensions as blocked rather than passed.
