# Task Evidence Collection Checklist

For each retained engineering, reasoning, tool-use, or frontend task, collect:

- Current task card and fixed contract
- Public input files and their hashes
- Trusted grader and private fixtures
- Runtime and dependency versions
- Independent valid reference implementations
- Targeted negative cases
- Exact calibration commands and logs
- Known ambiguities, exposure, and limits

Do not copy external project code or data into a task without checking its license and permitted use. Keep source provenance with the task package and keep private grading material out of the candidate projection.
