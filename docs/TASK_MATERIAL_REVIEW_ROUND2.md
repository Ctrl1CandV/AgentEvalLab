# Task Review Notes: Round 2

This historical review focused on task isolation, objective acceptance, and the review workflow.

## Retained decisions

- Default and augmented tool profiles must be independent conditions.
- A task prompt must not reveal private checks or later-stage requirements.
- Public checks must not modify the artifact used by the private grader.
- Incomplete evidence remains unknown; it must not be converted into a pass or failure.
- Visual judgments require screenshots and a separate human review record.
